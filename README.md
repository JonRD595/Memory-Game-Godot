# 🧩 Memory Game - Godot Edition

Memory Game es un proyecto basico que como su nombre lo indica, radica en un juego de memoria donde debes buscar los pares correctos y dependiendo de la dificultad pueden salir mas pares que unir y multiples preguntas logicas relacionadas a la teoria de conjuntos.

## 📖 Sobre el Proyecto
Este proyecto esta basado inicialmente en el trabajo de @Tzoop sobre un antiguo juego de adivinar los pares. Su finalidad solo era ser un trabajo academico, pero quizas el proyecto pueda escalar a algo mas, por ahora solo es una version muy temprana del mismo.
1. **Motor Gráfico:** Implementado en **Godot Engine 4.1.1** para aprovechar el sistema de nodos y señales.
2. **Optimización Web:** El juego fue exportado utilizando el modo de un solo hilo (Single-threaded) para garantizar compatibilidad total en navegadores sin necesidad de aislamiento de origen (SharedArrayBuffer).

## ⚙️ Características Técnicas
*   **Gestión de Estados:** Lógica de emparejamiento basada en estados para evitar errores de selección rápida.
*   **Cross-Platform:** Exportado para Web (HTML5), permitiendo su ejecución en dispositivos móviles y escritorio.
*   **Assets:** Fuentes y audio optimizados para carga rápida en entornos web.
